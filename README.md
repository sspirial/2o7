# 2o7

> *Kila stage ina stori.* (Every stop has a story.)

A 2D narrative adventure with micro-games for Android and web, set in Kenya during the turbulent 2007–08 post-election period. Experience the journey through the eyes of everyday Kenyans — from matatu rides across Nairobi to the stories whispered at every stage.

## Tech

- **Engine:** Godot 4 (GDScript)
- **Target:** Android (primary), Web (secondary)
- **Orientation:** Portrait (720×1280)

## Status

**M0 — Foundation**

Project skeleton established. Core systems, narrative content, and art assets are in development.

## Project Structure

```
2o7/
  scenes/       # All game scenes (.tscn)
  scripts/      # GDScript source files
  data/         # Narrative data (characters, chapters, rumours, archive)
  assets/       # Art, audio, UI, fonts
  tests/        # Test scenes and scripts
  docs/         # Design documents and references
```
